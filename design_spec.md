Billboard Builder design spec

Billboard builder is a web application where users can quickly arrange text, basic shapes, and images on a canvas, and export a PNG when finished. Think a slim version of Google Slides.

Features:
- Custom canvas sizes, with presets
- Custom font upload for text
- Alignment guides when dragging elements around
- Ability to add text, images, and basic shapes to the canvas.
- Ability to resize, stretch, etc., items on the canvas.
- Ability to change the stacking order of items on the canvas.

UI: Toolbar above, canvas below.
